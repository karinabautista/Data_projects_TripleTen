# TripleTen_projects
Projects I worked on while attending the Data Analysis TripleTen Bootcamp.


| Project number | Title | Description |
| :-----------: | ----------- |----------- |
| 1 | Monitoring Returns for SuperStore | The project task was to identify patterns and root causes of returns for the Superstore. |
| 2 | Strategic Performance Analysis for SuperStore | The project task was to evaluate profit, return rates, and advertising performance to uncover insights that could guide strategic business decisions. |
| 3 | Website Conversion & Retention Analysis | The project task was to construct a conversion funnel to measure how product page views translate into purchases and to perform cohort analysis by first purchase month to evaluate customer retention trends over time. |
| 4 | Shopify App Analysis | The project task was to analyze data from Shopify apps to identify key factors that contribute to app success, focusing on customer reviews, review helpfulness, developer response activity, and overall app ratings. |
