# TripleTen_projects
Projects I worked on while attending the Data Analysis TripleTen Bootcamp.


| Project number | Title | Description |
| :-----------: | ----------- |----------- |
| 1 | Monitoring Returns for SuperStore | The project task was to identify patterns and root causes of returns for the Superstore. |
| 2 | Strategic Performance Analysis for SuperStore | The project task was to evaluate profit, return rates, and advertising performance to uncover insights that could guide strategic business decisions. |
| 3 | E-Commerce Conversion Funnel & Cohort Analysis | The project task was to construct a conversion funnel to measure how product page views translate into purchases and to perform cohort analysis by first purchase month to evaluate customer retention trends over time. |
| 4 | Airbnb Investment Analysis: Manhattan Vacation Rentals | The project task was to analyze Airbnb data from the Manhattan vacation rental market to identify high-performing neighborhoods and property sizes and estimate the revenue potential of these listings to inform investment decisions. |
